# 網羅的議論法

意見に対する反論、その反論、その反論を表として展開するブラウザ完結アプリです。

`index.html` をブラウザで開くだけで使えます。Vite、サーバー、DBは不要です。

データはブラウザの `localStorage` に自動保存されます。JSON形式でインポート、エクスポートできます。意見ごとにページ分けしたPDFもダウンロードできます。

## PWAとして使う

GitHub PagesなどのHTTPSサイトで開くと、対応ブラウザのメニューからインストールできます。iPhone / iPadではSafariの共有メニューから「ホーム画面に追加」を選びます。

初回のオンライン読み込みでキャッシュの保存が完了すると、オフラインでも起動・編集・JSON入出力・PDFダウンロードができます。データは引き続き端末のブラウザに保存されます。大切な議論はJSONでバックアップしてください。

`file://`で直接開く使い方も可能ですが、インストールとオフラインキャッシュはHTTPSまたはlocalhostでのみ有効です。

公開時は `index.html`、`icon.svg`、`manifest.webmanifest`、`pwa.js`、`sw.js`、`icons/` を同じディレクトリに配置します。GitHub Pagesのサブディレクトリにも対応しています。アプリを更新するときは `sw.js` のキャッシュバージョン（`v1`）も変更してください。オンライン時は最新ファイルを取得し、Service Workerの更新は既存のアプリのタブ・ウィンドウをすべて閉じてから再度開くと適用されます。
